# PearchHA

Home Assistant values, history and controls in the macOS menu bar.

[Documentation](documentation.html) | [Download](https://github.com/YunaBraska/pearch_ha/releases/latest) | [Install](install.html)

## What it does

- Groups Home Assistant entities by room in a native menu-bar panel.
- Shows configurable values, gauges and history.
- Supports token and browser sign-in with Keychain-backed sessions.
- Provides capability-derived controls and service actions.

## Requirements

PearchHA supports macOS 13 and later and needs a reachable Home Assistant instance.
