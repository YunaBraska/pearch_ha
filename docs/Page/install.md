# Install

[Documentation](documentation.html) | [Install](install.html) | [PearchHA](index.html)

## Download

1. Open the [latest release](https://github.com/YunaBraska/pearch_ha/releases/latest).
2. Download the ZIP file.
3. Move `PearchHA.app` to Applications.

## Homebrew

```sh
brew tap yunabraska/tap
brew install --cask pearchha
```

## Source

```sh
swift build
swift test
```
